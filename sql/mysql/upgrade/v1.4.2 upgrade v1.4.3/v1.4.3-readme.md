# 升级至 V1.4.3 升级说明文档

本次版本主要新增 **数据管理 - API 接入** 功能，同时打通 API 类型任务的输入参数注入，以及模型输出结果定义（Result Visualization）。

## 一、数据库升级

### 方案一：全新环境（推荐）
直接执行 `initialization/v1.4.3初始化.sql`（已包含 `model_data_api` 建表、数据管理/API接入菜单及角色授权、请求方式字典大写等全部 V1.4.3 变更）。

### 方案二：存量环境（谨慎使用）
⚠️ 执行前请完整备份数据库并停止服务。
按顺序执行本目录内的：
1. `v1.4.3-update.sql` —— 建表 `model_data_api`
2. `v1.4.3-update-data.sql` —— 字典数据 + 菜单/权限

## 二、后端 & 前端

- 后端 `qmodel-module-model-biz` 新增 `modelData` 模块（Controller / VO / Convert / DO / Mapper / Service）。
- 计算引擎新增 `DataApiParameterResolver`，在 `ApiExecutionEngine`、`PythonExecutionEngine` 执行前自动调用绑定的数据 API，将响应 JSON 中同名字段覆盖到任务输入参数。
- `model_calc` / `model_config` **数据库表结构未变动**；`ModelCalcDO` 增加 5 个 `@TableField(exist=false)` 展示字段：`outputSchema / resourceName / resourceUrl / resourceMethod / resourceType`。
- 前端新增 `views/model/modelData/api/**` 页面、`api/model/modelData/modelDataApi.js`、`assets/icons/svg/apigl.svg`；`views/model/calc/**` 与 `views/model/modelManage/**` 有交互改动。

## 三、菜单与权限

菜单/按钮权限字符清单与占位说明详见 `v1.4.3-update-data.sql` 末尾注释区块。
- 权限前缀：`model:modelData:dataapi:*`
- 路由：`/data/api`、`/data/api/add`、`/data/api/edit`、`/data/api/detail`
