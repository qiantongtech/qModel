# 升级至 V1.4.4 升级说明文档

本次版本在数据库层面为**结构补全与废弃清理**：

## 一、数据库升级

### 方案一：全新环境（推荐）

直接执行 `initialization/v1.4.4初始化.sql`

### 方案二：存量环境（谨慎使用）

⚠️ 执行前请完整备份数据库并停止服务。
按顺序执行本目录内的：

1. `v1.4.4-update.sql` —— 结构变更：删除 6 张废弃表

> 两个脚本可重复执行：建表前均带 `DROP TABLE IF EXISTS`，新表在 V1.4.3 环境中本就不存在，删除为无害的空操作。
